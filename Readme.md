This project is designed to help teachers at our college efficiently **merge** and **filter** data stored in Excel sheets.

Faculty members often maintain and share data in Excel files, which are usually not normalized. As a result, merging different pieces of information to gain meaningful insights becomes a challenging task.

## ✅ Features of the Project

- Predefined Excel template for structured data entry
- Easy-to-use filtering options for categorical and numerical data types
- Automatic merging of datasets
- Export of merged and filtered data as a downloadable Excel file
